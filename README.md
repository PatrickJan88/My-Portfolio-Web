# Pofei Ran – Portfolio Website

Welcome to the personal portfolio repository of **Pofei Ran** — a Product Designer and AI Builder bridging Product Design, UI/UX Design, Human-Computer Interaction (HCI) Research, Artificial Intelligence, and Front-End Development.

This portfolio is not just a collection of visual templates; it is a meticulously crafted platform ("Portfolio OS") that scales gracefully, enforces design consistency, and serves as a living representation of Pofei's design philosophy and technical execution.

## 🌐 Live Website
https://pofeiportfolio.vercel.app/

## 🛠 Tech Stack
This project is built for performance, accessibility, and maintainability:
- **Framework:** React + Vite
- **Styling:** Tailwind CSS (Utility-first, minimal custom CSS)
- **Animations:** Framer Motion (Scroll-triggered reveals, subtle transitions)
- **Icons:** Lucide React
- **Language:** TypeScript

## 🧠 Architecture & Portfolio OS (`AGENTS.md`)
The core operating system of this portfolio is governed by **[AGENTS.md](./AGENTS.md)**. 
`AGENTS.md` is the single source of truth for:
- **Design Tokens:** Base scales, border radii, max-width system.
- **Motion Philosophy:** Guidelines for fade transitions, slide reveals, and respecting reduced motion preferences.
- **Content Authenticity & Storytelling:** Guardrails ensuring the focus remains on user-centered reasoning, verified research data, and avoiding unnecessary feature bloat.
- **AI Agent Operating Rules:** Guidelines to ensure AI automation systems (like this one) strictly respect the platform's architectural integrity when writing code.

Before contributing or modifying this repository, **you must read `AGENTS.md`**.

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## 🎯 Design Principles
- **Clarity over decoration**
- **Usability over complexity**
- **Storytelling over feature overload**
- **Accessibility first** (WCAG AA minimum)
- **Performance before visual excess**
