# Internal Design Manual & Product Resource Web — Media Assets

This dedicated folder stores all visual and video assets for the **Internal Design Manual & Product Resource Web** case study.

## Asset File Guide:
- **`cover.svg` / `cover.webp`**: Project card thumbnail used on the `/projects` directory grid (Recommended aspect ratio: `4:3`).
- **`hero.svg` / `hero.webp`**: Hero banner asset displayed at the top of the case study page (Recommended aspect ratio: `16:9` or `4:3`).
- **`media-1.svg` / `media-1.webp` or `media-1.webm`**: Full-width featured media above Section 1 (Interactive documentation hub / overview).
- **`media-2.svg` / `media-2.webp`**: Section 1 media asset (Design foundations, typography, tokens, or information architecture).
- **`media-3.svg` / `media-3.webp`**: Section 2 media asset (Component library, interactive playground, or guidelines).
- **`media-4.svg` / `media-4.webp`**: Section 3 media asset (Outcomes, design-to-code velocity, design system analytics).

When you drop your updated assets into this directory, update the paths in `src/data/projects/internal-design-manual.ts`.
